Guía de Configuración de Firebase

Para asegurar que loleteo guarde tus datos sin límites y que la sesión permanezca activa en tu móvil o navegador, verificá estos 3 pasos en tu consola de Firebase:

1. Google Authentication

En la consola de Firebase → Authentication → Sign-in method → Habilitá el proveedor Google.

2. Reglas de Seguridad en Firestore

En la consola de Firebase → Firestore Database → Rules (Reglas), pegá este bloque estricto para asegurar los paths obligatorios:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

3. Persistencia de Sesión Automática

Esta aplicación utiliza setPersistence(auth, browserLocalPersistence), lo que significa que una vez que inicies sesión en tu teléfono o PC, quedarás autenticado permanentemente hasta que toques voluntariamente "Cerrar sesión".
